# MGMT 2026 Week 5｜規劃與策略規劃

「澄川電控的三次選擇」是原創、中英雙語、三回合的策略模擬，供大二管理學 180 分鐘課堂使用。本套件為 2026-10-06 修訂版。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 互動網頁本體。單一檔案，CSS 與 JavaScript 內嵌，沒有 CDN、外部字型或 API 金鑰。 |
| `教學指引.md` | 給授課教師與助教的詳細指引：課前準備、逐段帶領與示範話術、學生問題的處理、英文板書配置、評量表與數值速查。另有 Word 版 `MGMT_W5_教學指引.docx`（不在本套件內）。 |
| `課程設計與教師帶領.md` | 教學設計、180 分鐘流程、常見問題；第十節列出本版的新增與待確認事項。 |
| `驗證紀錄.md` | 本版做過與沒做過的檢查。 |
| `test_w5_model.js` | 模型測試，只需要 Node.js。 |
| `test_w5_e2e.js` | 瀏覽器全流程測試，需要 Playwright。 |

## 開啟與部署

- 本機：用 Chrome、Edge、Firefox 或 Safari 直接開啟 `index.html`。操作不需要網路；外部教材連結與 AI 工具需要網路。
- GitHub Pages：把套件內的檔案放在 repository 根目錄，Settings → Pages → Deploy from a branch，選 main / root。本套件尚未替您部署。

## 課堂準備

1. 教師在「教師與規則」頁選定全班共同的事件路徑（預設為數位擴張），把該頁的連結發給各組。連結帶有路徑設定，例如 `…/index.html#w=dc`；加上 `&lang=en` 會以英文開啟。路徑只在模擬開始前可以更改。
2. 每組 4–5 人，角色為主持、財務、能力、訊號、挑戰者，每回合輪換。
3. 每位學生先各自寫初判，再整合成小組判斷。共用裝置時，個人初判先寫在紙上。
4. 每回合依 T0（小組初判，不使用 AI）→ T1（AI 查核）→ T2（關掉 AI，小組決定）進行。
5. 休息與下課前匯出 JSON 備份。課末每位學生完成個人反思，再匯出筆記。

## 保存與匯出

- 紀錄只存在目前的瀏覽器。不同裝置、不同瀏覽器或不同網址不會同步；無痕視窗或清除網站資料會讓紀錄消失。
- 同一瀏覽器開兩個分頁時，後寫入的分頁會同步到另一個分頁。
- JSON 可以還原進度（也接受前一版格式的備份）；Markdown 與 HTML 筆記供閱讀與繳交。
- 「下載可繼續操作的網頁」會把當下的紀錄存進一個新的 HTML 檔，該檔使用獨立的保存空間。
- 每個文字欄位上限 50,000 字。

## 模型邊界

所有數值都是教學假設，不代表產業估計。回合是規劃期間，沒有對應到年度財報；沒有情境機率、擲骰子或總分排名。現金、能力、客戶關係與彈性分開呈現。2030 年才投入的能力在模擬結束後才成熟。成果頁的 2032 延伸試算只是示意。這個模擬無法證明真實世界的最佳策略。
